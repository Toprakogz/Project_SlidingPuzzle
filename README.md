SLIDING PUZZLE GAME (C++)
A console-based Sliding Puzzle game developed in C++. This project demonstrates fundamental computer science concepts including dynamic memory allocation, custom data structures (Linked List-based Stack), heuristic algorithms (Manhattan Distance), file input/output operations, and user authentication.

FEATURES
Dynamic Board Sizing: Choose between different difficulty levels: 3x3, 4x4, and 5x5 grids.

Smart Heuristic Tracking: Calculates and displays the Manhattan Distance in real-time to show how close you are to solving the puzzle.

Stack-Based Undo System: Easily step back up to your last 5 moves using a custom linked-list stack implementation.

User Authentication System: Secure registration and login mechanism to manage individual players.

Save & Load Functionality: Save your current game state to a file and resume your progress later.

TECHNOLOGİES & CONCEPTS USED
Language: C++

Data Structures: Multi-dimensional dynamic arrays, Linked Lists, Stacks.

Algorithms: Manhattan Distance heuristic calculation, board shuffling algorithms.

File I/O: Persistent storage for user credentials and game states.
